## Requirements

- Linux (x86_64 or arm64)
- systemd
- `curl` and `sha256sum`
- Root / sudo access

Lookout does **not** require Go, Docker, or any runtime to be installed — the release artifact is a self-contained static binary.

## One-line installer

The recommended way to install Lookout is with the official install script. It downloads the correct binary for your architecture, verifies its checksum, creates a dedicated unprivileged system user, and registers a systemd service.

```bash
curl -fsSL https://raw.githubusercontent.com/AmoabaKelvin/lookout/main/install.sh | sudo sh
```

To pin a specific version:

```bash
VERSION=v1.0.0 curl -fsSL https://raw.githubusercontent.com/AmoabaKelvin/lookout/main/install.sh | sudo sh
```

After the script finishes, Lookout is **already running**. Alerts will print to the systemd journal until you configure a webhook.

## What the installer does

1. Detects your CPU architecture (`amd64` or `arm64`).
2. Resolves the latest release tag from GitHub (or uses `VERSION` if set).
3. Downloads the binary and verifies its SHA-256 checksum against the published `checksums.txt`.
4. Installs the binary to `/usr/local/bin/lookout`.
5. Creates a locked-down system user `lookout` (no home directory, no login shell).
6. Writes a config template to `/etc/lookout/lookout.env` — **only on first install**; re-running never overwrites an existing config.
7. Installs and enables the systemd unit `lookout.service`.

## Next steps

```bash
# 1. Open the config and add your webhook URL
sudo nano /etc/lookout/lookout.env

# 2. Restart to apply the new config
sudo systemctl restart lookout

# 3. Stream the logs to confirm it's running
journalctl -u lookout -f
```

## Manual installation

If you prefer not to pipe a script to `sudo sh`, you can install manually:

```bash
# 1. Download the binary for your architecture
curl -fsSL https://github.com/AmoabaKelvin/lookout/releases/latest/download/lookout-linux-amd64 \
  -o /usr/local/bin/lookout
chmod +x /usr/local/bin/lookout

# 2. Create the service user
useradd --system --no-create-home --shell /usr/sbin/nologin lookout

# 3. Create the config directory
mkdir -p /etc/lookout
# Then write your /etc/lookout/lookout.env (see Configuration)

# 4. Create the systemd unit
cat > /etc/systemd/system/lookout.service <<EOF
[Unit]
Description=Lookout monitoring agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=lookout
Group=lookout
ExecStart=/usr/local/bin/lookout
EnvironmentFile=/etc/lookout/lookout.env
Restart=always
RestartSec=5
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
EOF

# 5. Enable and start
systemctl daemon-reload
systemctl enable --now lookout
```

## Uninstalling

```bash
systemctl stop lookout
systemctl disable lookout
rm /etc/systemd/system/lookout.service
rm /usr/local/bin/lookout
rm -rf /etc/lookout
userdel lookout
systemctl daemon-reload
```
